# claude-plugins

Catalogo (marketplace) dei miei plugin per [Claude Code](https://claude.com/claude-code).

```bash
claude plugin marketplace add cosentino/claude-plugins
```

| Plugin | Descrizione | Installazione |
|---|---|---|
| [hew-woodworking](plugins/hew-woodworking) | Progettare mobili in legno con [Hew](https://hew3d.com): modello 3D come codice, quote, pagina 3D navigabile anche da telefono, distinta di taglio ottimizzata e PDF per il rivenditore. | `claude plugin install hew-woodworking@cosentino` |
